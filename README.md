# Elektor Pico Primer Kit

This bundle was originally sold (in 2021-2025) by [Elektor](https://www.elektor.com) and made by [Makerfabs](https://www.makerfabs.com) with MicroPython example codes.

![Elektor Pico Primer Kit](assets/Elektor_PicoPrimerKit.png "Credit : Elektor")
*Credit : Elektor*

This kit consists of a main board with a TFT LCD screen (1.44" ST7735 driver), different components and connectors, for the Raspberry Pi Pico and the following accessories :

* on the board : 3 push buttons, 3 LEDs, 1 buzzer, 6 connectors
* 1 slide potentiometer
* 1 10A relay
* 1 strip of 8 LEDs (WS2818)
* 1 Inertial Measure Unit MPU6050 with 6 axes (accelerometer, gyroscope)
* 1 ultrasonic distance sensor (HC-SR04)
* 1 servomotor (SG90)
* 1 serial to WIFI (ESP module)
* 1 humidity and temperature sensor (DHT11)

This repository is an attempt to port MicroPython codes to the CircuitPython environment (version 9 for now) for educational projects.
