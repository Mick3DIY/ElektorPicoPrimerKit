## Example codes

> [!TIP]
> First of all, you need to install CircuitPython (version 10.x, stable version) in your the Raspberry Pi Pico !
> Follow this link for instructions, download it (in your language) and how to install it : 
> https://circuitpython.org/board/raspberry_pi_pico/
>
> To upload example codes and run them in your Pico , you need a simple software like Tonny IDE : https://thonny.org
